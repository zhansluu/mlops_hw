# MLOps Homework

Проект реализует полный MLOps пайплайн для обучения модели ResNet18 в рамках домашнего задания.

## Стек
- **PyTorch** — обучение ResNet18
- **TensorBoard** — логирование метрик 
- **MinIO (S3)** — хранение артефактов моделей
- **DVC** — версионирование пайплайна и воспроизводимость экспериментов

## Результаты
| Модель | Accuracy | F1 | Loss |
|--------|----------|----|------|
| v1 (Train_1, 10 эпох) | 96.50% | 96.50% | 0.0879 |
| v2 (finetune Train_2, 5 эпох) | 97.85% | 97.85% | 0.0718 |
